# Omawing

An Amiga-inspired flight demo for Omarchy. Cruise through nine neon worlds,
or take control, chain rings, and chase a high score.

[![Omawing in motion: swept wings and glowing twin engines over the Vector Garden](docs/media/flight.webp)](docs/gallery.md)

Swept wings that flex and fold under boost, twin cyan-to-magenta exhausts,
checkerboard landscapes, copper skies, and a three-track soundtrack.
Built as a native C++ / Qt Quick app, with live Omarchy themes and 50 languages.

**[Gallery](docs/gallery.md) · [Playing & controls](docs/playing.md) · [Installation](docs/install.md) · [Development](docs/development.md)**

## Try it

Download a package from the [latest release](https://github.com/thepixelgardener-create/omawing/releases/latest),
or build and run the current source:

```sh
git clone https://github.com/thepixelgardener-create/omawing
cd omawing
bin/build && build/omawing
```

Build dependencies and package verification are in the [installation guide](docs/install.md).
Use **WASD / arrow keys** to fly, **Shift** to boost, **T** for autopilot,
**M** for music, and **?** for all shortcuts.

The preview shows the current source; packaged releases may differ.
